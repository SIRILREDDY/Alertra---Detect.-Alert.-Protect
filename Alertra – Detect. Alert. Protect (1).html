How Alertra decides

Every transaction passes through the same three stages.

Read

The loader detects the file type, pulls out transaction IDs, counterparties and signed amounts from Excel, CSV, PDF tables or OCR'd images.

Connect

Accounts become nodes in a payment graph. A GraphSAGE network scores each account on its connections, PageRank and spending habits.

Decide

Account scores, ring membership and unusual amounts combine into one risk score and a clear action with the reason attached.

Decision rules

The risk score is a weighted sum, capped at 100%. Each flagged transaction lists why it was flagged.

  • Source account risk40% weight
  • Target account risk30% weight
  • Part of a fraud ring+40 points
  • Amount above baseline + 3σ and over 1,000+20 points

The score maps to one of three actions.

  • Reject and freezeRing member, or score 80% and above
  • Step-up authenticationScore 45% to 79%
  • ApproveScore below 45%

The engine

The core of Alertra, written in Python with PyTorch Geometric and NetworkX. Run it in Google Colab or locally.

class FraudGNN(nn.Module):
    def __init__(self, in_channels, hidden_channels, out_channels):
        super().__init__()
        self.conv1 = SAGEConv(in_channels, hidden_channels)
        self.conv2 = SAGEConv(hidden_channels, out_channels)

    def forward(self, x, edge_index):
        x = F.relu(self.conv1(x, edge_index))
        x = F.dropout(x, p=0.2, training=self.training)
        return torch.sigmoid(self.conv2(x, edge_index))
